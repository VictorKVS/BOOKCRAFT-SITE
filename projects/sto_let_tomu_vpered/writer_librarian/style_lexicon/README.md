# Writer Style & Lexicon Engine v1

Purpose: transform a structurally correct scene into readable literary prose without changing canon, facts, causality, character intent, or scene outcome.

## Pipeline

CANON SCENE
-> semantic lock
-> lexical enrichment
-> emotion/behavior rendering
-> rhythm and sentence-shape pass
-> voice/style profile
-> repetition and filler cleanup
-> literary quality checks
-> final prose

## Core layers

1. LEXICON
   - gaze / face / gesture / posture
   - motion and action verbs
   - speech verbs
   - sensory vocabulary
   - emotional manifestations
   - environment and atmosphere
   - synonym groups
   - filler-word replacement

2. BEHAVIOR RENDERING
   - convert internal state into observable behavior
   - physical signs and sensations are suggestions, not diagnostic truth
   - writer-reference heuristics are separated from scientifically verified behavior knowledge

3. STYLE PROFILE
   - sentence length distribution
   - syntax complexity
   - narrator distance
   - dialogue density
   - metaphor density
   - sensory detail
   - interiority
   - pacing
   - lexical register
   - irony / restraint / lyricism

4. VOICE PRESERVATION
   - each character gets its own vocabulary, sentence habits, taboo words, education/profession markers, speech tempo and emotional masking.

5. SAFETY / FIDELITY
   - no plot changes in style pass
   - no new facts
   - no changed motivation
   - no invented world rules
   - semantic diff must pass before replacing source draft

## Author-style policy

Public-domain authors may have named style profiles built from measurable traits and public-domain text.
For living authors, use a trait-based profile rather than direct imitation.

Example public-domain profiles:
- Tolstoy: social/psychological observation, long syntactic periods, concrete physical detail, moral interiority, scene-level social dynamics.
- Chekhov: compression, implication, restrained emotional naming, observational detail, subtext.
- Dostoevsky: psychological pressure, argumentative dialogue, interior conflict, heightened moral stakes.

These are editable craft profiles, not claims that the engine can reproduce an author perfectly.
