# LEGACY CONTINUATION MODE

## Goal

Reconstruct a literary world's operational model from a corpus and use it to propose causally plausible future branches while preserving a strict boundary between source canon, historical reality, authorial assumptions, and newly generated hypotheses.

This mode is not "copy the author." It is a simulation-and-evaluation pipeline.

## Core layers

1. SOURCE CORPUS
2. CANON MODEL
3. HISTORICAL REALITY MODEL
4. AUTHORIAL DEVIATION MODEL
5. WORLD STATE
6. CHARACTER COGNITIVE MODELS
7. RELATIONSHIP MODEL
8. FACTION / HOUSE MODEL
9. OPEN THREAD GRAPH
10. AUTHOR INTENT (optional, user-owned)
11. STORY COMPOSITION ENGINE
12. BRANCH SIMULATOR
13. STYLE & LEXICON PASS
14. CANON / LOGIC / HISTORY / CONTINUITY CHECK
15. EVALUATION

## Four truth classes

Every world fact must carry one of:

- HISTORICAL_FACT
- CANON_FACT
- AUTHORIAL_ASSUMPTION
- GENERATED_HYPOTHESIS

Generated hypotheses are never silently promoted to canon.

## Historical-world model

Track at minimum:

- date / chronology
- geography
- political actors
- factions / houses / clans
- economy and trade
- agriculture
- technologies and crafts
- military capabilities
- communications and travel time
- law / custom / religion
- demographics
- climate / season
- disease / medicine
- resources and logistics

## Character cognitive model

For each important character:

- education
- profession / skills
- prior life experience
- knowledge actually demonstrated in corpus
- knowledge limits
- decision style
- risk tolerance
- moral constraints
- recurring heuristics
- blind spots
- relationships
- stress response
- learning / change over time

Rule: the engine may not grant a character knowledge merely because a modern reader has it.

## World autonomy

The world continues without the protagonist.

Independent processes include:

- political decisions
- faction strategies
- economic changes
- military movements
- trade / resource shifts
- family and relationship dynamics
- disease / weather / harvest
- historical events

## Story composition

The engine combines multiple active pressures rather than serializing isolated subplots:

HISTORY + WORLD + CHARACTER + RELATIONSHIP + FACTION + OPEN THREADS + AUTHOR INTENT
-> collisions
-> consequences
-> new state
-> candidate branches

## Branch scoring

Each candidate branch receives:

- canon_consistency
- character_consistency
- historical_plausibility
- causal_strength
- open_thread_relevance
- relationship_consistency
- faction_logic
- novelty
- dramatic_value
- setup_payoff_quality

## Long-cycle continuity

Track:

- main arc
- character arcs
- faction arcs
- relationship / intimacy arcs
- unresolved promises
- latent threats
- delayed consequences
- hidden information
- state changes across books

## Game scenario extension

The same world model can be exported into a GAME NARRATIVE mode:

- story graph
- quest graph
- decision graph
- consequence graph
- faction graph
- ending graph
- scene specifications
- presentation specifications

This is a separate rendering/export layer over the same narrative state engine.
