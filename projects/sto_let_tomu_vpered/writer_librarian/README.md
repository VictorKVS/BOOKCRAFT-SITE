# FATHER Writer Librarian v1

Writer Librarian is the domain profile of the universal FATHER/OSINT Librarian for fiction research and narrative design.

## Mission

Turn external writing knowledge into a traceable, structured, reusable knowledge base for ALINA Story Architect.

The Librarian does not write prose by default. It:
1. discovers sources;
2. validates source identity and freshness;
3. classifies material;
4. extracts narrative patterns and craft rules;
5. stores provenance;
6. routes knowledge to Story Architect, Human Behavior Model, Dramaturg and Canon checks.

## Source policy

Every knowledge item must preserve:
- source_id
- source_url
- source_title
- publisher/author when known
- retrieved_at
- content_type
- authority_level
- verification_status
- license_or_usage_note
- extracted claims/patterns
- provenance

No source -> no trusted knowledge.
No provenance -> no trusted Writer KB edge.

## Knowledge tiers

### TIER A — Primary craft frameworks
Named frameworks, official sites, original authors/publishers, or authoritative documentation.

### TIER B — Professional educational resources
Established writing schools, editors, publishers, and long-running craft sites.

### TIER C — Community / heuristic references
Useful examples, infographics, forum discussions, social posts and secondary summaries. Never treated as authoritative psychology or universal law.

## First acceptance target

Build 50-100 normalized narrative patterns before enabling automatic story generation.

Each pattern should capture:
- name
- family
- genre compatibility
- beats
- prerequisites
- conflict model
- character requirements
- tension curve
- information/reveal curve
- common failures
- cliche risk
- compatible patterns
- source provenance
