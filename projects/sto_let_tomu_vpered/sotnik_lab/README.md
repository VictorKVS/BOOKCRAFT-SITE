# SOTNIK LAB

Experimental benchmark for FATHER / ALINA Legacy Continuation Mode.

## Objective

Reconstruct and evaluate a complex historical-fiction world before generating any continuation.

The lab separates:

- CANON_FACT
- HISTORICAL_FACT
- AUTHORIAL_ASSUMPTION
- GENERATED_HYPOTHESIS

## Pipeline

CORPUS
-> INGEST
-> EVIDENCE
-> CANON
-> WORLD/HISTORY
-> CHARACTERS
-> FACTIONS/POWER
-> INNOVATIONS
-> OPEN THREADS
-> WALK-FORWARD BACKTEST
-> BRANCH SIMULATION
-> STYLE PASS
-> VALIDATION

## Rule

NO SOURCE -> NO CANON.
NO FROZEN FORECAST -> NO BACKTEST.
NO BACKTEST -> NO CLAIM THAT THE SYSTEM UNDERSTANDS THE SERIES.

## First benchmark questions

1. Can ALINA reconstruct the world state across books?
2. Can it distinguish history from the author's alternate-history assumptions?
3. Can it model the protagonist's demonstrated knowledge and limits?
4. Can it track multiple concurrent political, military, economic and personal arcs?
5. Can it detect unresolved assets/technologies/organizations (e.g. inherited systems)?
6. Can it predict which threads are likely to reappear in the next known book?
7. Can it estimate second- and third-order effects of innovations?
