# Cross-project visual assets

Scope: Mixed assets from all projects

## Statuses

- SELECTED — active chosen asset
- CANDIDATE — usable candidate
- REFERENCE — reference only
- NEEDS_VISUAL_REVIEW — cannot be safely classified from filename alone

## Rule

Files whose project cannot be safely inferred from filename are grouped by month under `_needs-review/`. This avoids false assignment to ALINA, Makar, OSINT, SecGraph, OTUS or another project.
