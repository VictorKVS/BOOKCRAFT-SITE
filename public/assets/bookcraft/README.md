# BOOK-CRAFT visual assets

Эта папка предназначена только для сменных визуальных ассетов.

Правило:
- текст интерфейса не запекаем в PNG/WebP;
- кнопки не рисуем внутри изображений;
- HUD и графики не являются картинкой;
- маршруты и состояния остаются React-компонентами;
- hero character желательно хранить отдельно от background.

Структура:
- `hero/` — главный персонаж;
- `backgrounds/` — фон/интерьер;
- `props/` — предметные слои;
- `cards/` — изображения четырёх продуктовых карточек;
- `manifest.json` — контракт слотов.
