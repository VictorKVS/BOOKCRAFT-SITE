# ДЗ PRO AI Контент-Мейкер — сценарий итогового видео

Рекомендуемая длительность: **60–90 секунд**.

Base URL:

`http://127.0.0.1:5180/`

## 00:00–00:08 — Главная

Открыть:

`http://127.0.0.1:5180/`

Показать:

- BOOK-CRAFT;
- hero;
- смену визуальных вариантов;
- четыре продуктовые карточки;
- блок трёх основных потоков.

Текст для озвучки:

> BOOK-CRAFT — мой прототип AI Content Maker. Одна идея превращается в несколько связанных форматов контента в едином интерфейсе.

## 00:08–00:22 — Рассылка

Открыть:

`http://127.0.0.1:5180/mailing?demo=1`

Показать:

- тему;
- аудиторию;
- цель;
- тон;
- готовые SUBJECT / PREHEADER / BODY.

Озвучка:

> Первый обязательный поток — рассылка. Пользователь задаёт тему, аудиторию, цель и тон, после чего получает структурированный текст письма.

## 00:22–00:35 — Подкаст

Открыть:

`http://127.0.0.1:5180/podcast?demo=1`

Показать:

- сценарий;
- формат;
- голос;
- waveform;
- кнопку воспроизведения.

Озвучка:

> Второй поток — подкаст. Сценарий проходит через голосовой пайплайн и подготавливается к синтезу речи.

## 00:35–00:50 — Видео-Аватар

Открыть:

`http://127.0.0.1:5180/video-avatar?demo=1`

Показать:

- каталог аватаров;
- каталог голосов;
- выбранную пару;
- сценарий;
- video job.

Озвучка:

> Третий поток — видео-аватар. Интерфейс предусматривает получение списка голосов и аватаров внешнего сервиса и подготовку video job.

Важно: если реальный HeyGen/другой API ещё не подключён, не говорить, что это live API. До подключения называть состояние API DEMO.

## 00:50–01:02 — Дополнительная вкладка

Открыть:

`http://127.0.0.1:5180/longread?demo=1`

Показать готовую структуру материала.

Озвучка:

> Дополнительная вкладка — Лонгрид. Из темы, аудитории и редакционного тона собирается структура большого материала.

## 01:02–01:12 — Бонусный image workflow

Открыть:

`http://127.0.0.1:5180/images?demo=1`

Показать промпт и выбранный вариант.

Озвучка:

> Дополнительно в BOOK-CRAFT предусмотрен визуальный модуль генерации изображений.

## 01:12–01:20 — Финал

Открыть:

`http://127.0.0.1:5180/demo`

Показать карту screenshot-state страниц.

Озвучка:

> Все разделы собраны в едином BOOK-CRAFT интерфейсе. Отдельные системные промпты хранятся в коде проекта, а итоговые состояния подготовлены для проверки и публикации.

## Настройки записи

- браузер: 100% scale;
- желательно 1920×1080;
- не показывать API keys, терминал с секретами и личные данные;
- курсор двигать медленно;
- перед записью закрыть лишние вкладки;
- для красивой записи использовать полноэкранный режим браузера;
- сохранить как `BOOKCRAFT_DZ_PRO_DEMO.mp4`.
